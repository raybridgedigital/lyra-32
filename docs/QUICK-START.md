# LYRA-32 — quick start

Open the app in Chrome, Edge, or Firefox.

## Play in 30 seconds

1. Click any on-screen piano key, or press **A**. The first click unlocks audio (browser rule). The header should read **Live**.
2. Choose a patch from the menu in the center of the header.
3. Play.
4. Plug a USB-C MIDI keyboard and **Allow** MIDI when asked. Hide the on-screen piano with the keyboard icon.

## If there is no sound

- **Live** must be gold, not Idle — click a key once.
- **Mute** must not be gold.
- Unmute the Chrome tab (right-click the tab).
- **Panic** (or Esc) if a note is stuck.

## Three ways to play

| Source | How |
|---|---|
| On-screen piano | 3 octaves at the bottom. Hide it when you use hardware. |
| Computer keys | **A** = C. Blacks on W E T Y U O P. Octave **Z** / **X**. |
| USB MIDI | M-Audio etc. Pitch wheel, mod wheel, sustain, aftertouch all work. |

## Knobs

Click and drag **up/down**. Up = clockwise. Help is the **?** button in the header (or press **?**).

## Try these patches

- **Init Dual Saw** — default keys
- **Scream Super** / **Howl Super** — stacked lead
- **Sub Current** — bass
- **Techno Seq** — arp + 16-step pattern already running
